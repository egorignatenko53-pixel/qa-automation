# QA Automation

Учебный проект по автоматизации тестирования на Java.
Первые шаги в автотестах в рамках перехода из manual QA в AQA.

## Стек

- Java
- Maven — система сборки и управления зависимостями
- JUnit 5 — фреймворк для автотестов

## Что здесь есть

- `src/main/java` — тестируемый код (класс `Calculator`)
- `src/test/java` — автотесты на JUnit (`CalculatorTest`)

## Изученное

- Настройка Maven-проекта, подключение зависимостей через `pom.xml`
- Написание тестов с аннотацией `@Test`
- Проверки (assertions): `assertEquals`, `assertTrue`, `assertFalse`
- Принцип «ожидаемое vs фактическое» значение

### API-тесты
- REST Assured: GET-запросы, проверка статус-кода и полей JSON

## Как запустить тесты

Открыть проект в IntelliJ IDEA и запустить класс `CalculatorTest`
(зелёный треугольник рядом с классом), либо командой Maven:

    mvn test
