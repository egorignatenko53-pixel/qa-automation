# QA Automation

Проект по автоматизации тестирования на Java.
Портфолио в рамках перехода из manual QA в AQA.

## Стек

- **Java** — язык программирования
- **Maven** — система сборки и управления зависимостями
- **JUnit 5** — фреймворк для юнит-тестов
- **REST Assured** — библиотека для API-тестов

## Что реализовано

### Юнит-тесты (JUnit)
- `CalculatorTest` — тесты арифметики (сложение, деление, деление на ноль)
- `BankAccountTest` — тесты класса с состоянием: пополнение,
  снятие, проверка ошибок, операции подряд
- Используются: `@Test`, `@BeforeEach`, `assertEquals`,
  `assertTrue/assertFalse`, `assertThrows`, параметризованные тесты

### API-тесты (REST Assured)
- `CheckAPITest` — тесты REST API на примере JSONPlaceholder
- Покрыты все основные операции: GET, POST, PUT, PATCH, DELETE
- Проверка статус-кодов и полей JSON в ответе
- Логирование запросов и ответов (`.log().all()`)
- Структура тестов given–when–then

## Структура проекта

- `src/main/java` — тестируемый код (Calculator, BankAccount)
- `src/test/java` — автотесты

## Как запустить тесты

Открыть проект в IntelliJ IDEA и запустить нужный тестовый класс
(зелёный треугольник рядом с классом), либо через Maven:

    mvn test
